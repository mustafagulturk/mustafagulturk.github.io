# mustafagulturk.github.io

Kişisel portfolyo sitem. Projelerimi, yeteneklerimi ve iletişim bilgilerimi içerir.

**Canlı site:** https://mustafagulturk.github.io

## Teknolojiler

- HTML5, CSS3 (CSS değişkenleri, Grid, Flexbox)
- Vanilla JavaScript (açık/koyu tema, kaydırma animasyonları)
- GitHub Pages ile yayınlama

## Özellikler

- Mobil uyumlu (responsive) tasarım
- Açık / koyu tema desteği, tercih tarayıcıda saklanır
- Bölümler ekrana girerken yumuşak animasyon
- Hiçbir framework veya build adımı gerektirmez

## Yerelde çalıştırma

```bash
git clone https://github.com/mustafagulturk/mustafagulturk.github.io.git
cd mustafagulturk.github.io
# index.html dosyasını tarayıcıda aç
```
